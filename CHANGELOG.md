# Changelog

## 1.2.0

- Show Python special methods such as `__init__` and `__str__` in bright purple in the preview.
- Color Python magic method names from their `support.function.magic.python` TextMate scope.
- Style built-in Python functions lavender, matching the PyCharm reference screenshot, and clarify their distinction from language keywords.
- Match the PyCharm keyword colors: `class` in golden yellow and `def` in green.

- Bring syntax colors closer to the JetBrains Dark editor palette.
- Use sand-colored enum values and blue method calls, distinct from receiver variables.
- Preserve separate colors for classes, built-in types, attributes, parameters and keyword arguments.
- Update the neutral English Python preview and example source.
